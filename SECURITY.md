# Report a security concern privately

If you believe you have found a security or privacy issue in DKlutter, email **[maxwellinnovativetechnologies@gmail.com](mailto:maxwellinnovativetechnologies@gmail.com)**.

Please describe what happened, the app version and the steps needed to reproduce it. Do not include passwords, access tokens or another person’s private information.

Please do not publish sensitive details in a GitHub issue. A private report gives us a chance to investigate and help protect users.
